## 🏦 国库系统资金流向

### 资金流入
```
来源：RBS 合约通过 depositStableReserve()
机制：
  1. RBS 授权 Treasury 使用 BSC-USD
  2. 调用 depositStableReserve(usd, amount, profit)
  3. 国库计算铸造金额 = 价值 - 利润
  4. 铸造新的 PRO 代币给 RBS
  5. 更新 totalReserves

当前储备：
  - 1,800,100 BSC-USD（约 $180 万）
  - 303 tUSD
  - 1 BNB Anniversary Coin NFT
```

### 资金流出
```
用途：
  1. MintRewards：向质押系统发放奖励
  2. Manage：授权管理者提取储备金

限制：
  - 仅限授权管理者
  - 需要 excessReserves() 足够
  - 队列系统延迟角色变更
```

## 🎯 质押系统资金流向

```

  2. 合约记录质押份额（sPro）
  3. Rebase 机制调整奖励率

当前质押：
  - 718,477.87 PRO（实际代币）
  - 10,912,742.24 sPro（质押份额）
```

### 资金流出
```
机制：Rebase 调整
  - 每 12 小时触发一次
  - 由 0x3A2C7351...78508f648 调用
  - 通过算法调整 sPro/Pro 比率
  - 无直接代币转账

说明：
质押奖励通过 Rebase 机制分配，不是直接转账。
用户的 sPro 余额保持不变，但每个 sPro 对应的 PRO 增加。
```
