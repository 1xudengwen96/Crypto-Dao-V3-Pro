## 📊 四、USDT 详细分配百分比

### USDT 入场后的分配决策

当一个用户或系统向生态系统注入 USDT 时，资金按以下路径分配：

#### 场景 A：用户通过 PancakeSwap 购买 PRO

```
用户支付 USDT 购买 PRO
    │
    ▼
┌───────────────────────────────────────────────────────┐
│                   PancakeSwap LP 池                    │
│                                                       │
│  用户 USDT → ─────────────────→ LP 池 (69.9%)        │
│  LP 池 PRO → ─────────────────→ 用户钱包              │
│                                                       │
│  卖出时：3% 税收 → feeReceiver 地址                   │
└───────────────────────────────────────────────────────┘

分配比例：
- 100% USDT 留在 LP 池中（作为流动性）
- 3% 卖出税额外流向 feeReceiver
```

#### 场景 B：RBS 铸造新 PRO 并添加流动性

```
RBS 调用 mint(usdAmount, profitAmount)
    │
    ├──► profitAmount (~0-20%) → 保留在 RBS 作为运营费用
    │
    └──► 铸造的 PRO → RBS 持有
              │
              ▼
         RBS 调用 addLiquidity(USDT, PRO)
              │
              ├──► USDT (50% 等值) → LP 池
              │
              └──► PRO (50% 等值) → LP 池

分配比例（以 RBS 操作为例）：
- ~50% USDT 价值 → 配对 PRO 添加到 LP 池
- ~22.3% → 保留在 RBS 作为铸造储备
- ~7.7% → 转移至国库作为储备支撑
- ~20% → 铸造利润（profitAmount）保留
```

#### 场景 C：USDT 注入系统的完整百分比拆解

假设注入 **$1,000,000 USDT** 到整个生态系统：

| 去向 | 金额 | 百分比 | 说明 |
|------|------|--------|------|
| **LP 流动性池** | $699,000 | 69.9% | 提供交易流动性，用户可自由买卖 |
| **RBS 运营储备** | $223,000 | 22.3% | 用于未来铸造 PRO 和做市操作 |
| **国库储备** | $77,000 | 7.7% | 作为 PRO 铸造的储备支撑 |
| **卖出税** | $300 × 每笔卖出 | 3% | 每次卖出额外征收，流向 feeReceiver |

> **重要**：以上百分比基于当前链上分布的静态快照。实际分配会随 RBS 操作和用户交易动态变化。

## 🔍 六、关键 USDT 流转路径分析

### 路径 1：用户购买 PRO（USDT → LP → 用户）

```
用户钱包 (1000 USDT)
    │
    │ swap on PancakeSwap
    ▼
LP 池 (0x6384...d50c3)
    │
    │ USDT 进入池子
    │ PRO 离开池子给用户
    ▼
用户钱包 (16.5 PRO) + LP 池 USDT 增加
```

**影响**：
- LP 池 USDT 增加 → 总流动性增加
- LP 池 PRO 减少 → PRO 价格轻微上涨
- 不影响 RBS 或国库的 USDT

### 路径 2：用户卖出 PRO（PRO → LP → USDT）

```
用户钱包 (10 PRO)
    │
    │ swap on PancakeSwap
    ▼
LP 池 (0x6384...d50c3)
    │
    │ PRO 进入池子
    │ USDT 离开池子给用户
    │ 3% 卖出税 → feeReceiver
    ▼
用户钱包 (~575 USDT) + feeReceiver (~17.5 USDT) + LP 池 PRO 增加
```

**影响**：
- LP 池 USDT 减少 → 总流动性减少
- LP 池 PRO 增加 → PRO 价格轻微下跌
- 3% 税外流到 feeReceiver（不在系统内循环）

### 路径 3：RBS 铸造 + 添加流动性（USDT → Treasury → PRO → LP）

```
RBS (5,208,232 USDT)
    │
    │ mint(200,000, 40,000)
    ▼
Treasury (+200,000 USDT)
    │
    │ 铸造 160,000 PRO 等值 → RBS
    ▼
RBS (+160,000 PRO 等值)
    │
    │ addLiquidity(USDT, PRO)
    ▼
LP 池 (+80,000 USDT + 1,321 PRO)
    │
    │ 获得 LP Token → RBS
    ▼
RBS 持有 LP Token
```

**影响**：
- RBS USDT 减少 → 但获得 PRO
- Treasury USDT 增加 → 储备增加
- LP 池 USDT 和 PRO 同时增加 → 总流动性增加
- RBS 获得 LP Token 可后续燃烧

### 路径 4：RBS 燃烧 LP（USDT 永久移除）

```
RBS 持有 LP Token
    │
    │ burnLP()
    ▼
DEAD 地址 (0x000...dEaD)
    │
    │ LP Token 永久销毁
    ▼
LP 池总流动性永久减少
```

**影响**：
- LP 池 USDT 和 PRO 同时被"锁定"（无法取出）
- 减少市场流动性 → 可能增加价格波动
- 通缩操作
